# Contributing

This repository is a **read-only mirror**. Every file here is generated from
AgentMore's main tree and republished on every release, so a commit pushed here
is overwritten by the next sync.

Issues and pull requests are still welcome and still read — a PR is a fine way
to show a fix. It gets applied upstream and lands here on the following sync.

A skill file is also served live at its own public URL (for example
<https://agentmore.app/skill.md>), so the fastest way to check what a skill
currently says is to fetch it rather than to read this mirror.

For anything urgent, or a security report, email `rick@agentmore.app`.
